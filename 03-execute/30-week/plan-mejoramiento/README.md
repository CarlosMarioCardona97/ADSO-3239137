# Archive — Préstamo de expedientes de un archivo municipal

Sistema para que el archivo municipal lleve su catálogo de expedientes, los funcionarios que los
solicitan y los préstamos, y vea qué expedientes se piden más.

| [`page/`](page/) | Sitio público estático del producto |
| [`infra/`](infra/) | Contenedores: base de datos, API y frontend con un solo comando |
| [`tool/`](tool/) | Sembrador de datos de demostración por la API |
